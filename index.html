Spider Benchmark Complexity Tiers

Spider categorizes SQL tasks into four progressive difficulty levels:

  • Easy: Single table filters, simple ordering, basic limits.
  • Medium: 2-table JOINs, standard aggregations (SUM, AVG, COUNT), GROUP BY.
  • Hard: 3+ table JOINs, GROUP BY with HAVING, nested subqueries, date transforms.
  • Extra Hard: Correlated subqueries, self-joins, set operations (INTERSECT, EXCEPT, UNION).
SQLGenX Dual Database Architecture

How SQLGenX connects to both production and sandbox databases:

  • Live MySQL Connection: Connect directly to your local or cloud MySQL database to generate and execute queries on real data.
  • Sample Enterprise Sandbox: Zero-setup in-browser SQLite database (1,900+ rows) ready whenever MySQL is offline or disconnected.
  • Interactive ER Visualizer: Visual diagram of tables, foreign-key relationships, and column schemas.
  • Read-Only Guardrail: Blocks all mutating DDL/DML operations (DROP, DELETE, UPDATE) across all databases.
